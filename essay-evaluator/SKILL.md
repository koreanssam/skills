# 📝 essay-evaluator (서술형 수기 답안 평가 스킬)

이 스킬은 학생들의 **손글씨 서술형 답안지(PDF/이미지)**를 분석하여 루브릭 기반으로 자동 채점하고 피드백을 생성하는 스킬입니다.

> [!IMPORTANT]
> **모든 학생 수기 답안지는 절대로 유추나 임의의 텍스트로 처리해서는 안 되며, 반드시 `view_file` 도구를 사용해 각 이미지/PDF 페이지를 직접 시각적으로 열어보고 필기 내용을 100% 교차 검증하여 채점해야 합니다.**

---

## 🛠️ 사전 요구사항
1. Python 3 및 필요 패키지 (`pdf2image`, `Pillow`, `pandas`, `openpyxl`)
2. 에이전트의 `view_file` 도구를 사용하여 수기 답안 이미지를 직접 시각적으로 열람

---

## 🏃 워크플로우 실행 단계

### 1단계: 원본 답안지 PDF 분할 및 개별 이미지화
제출된 수기 답안지 PDF 파일(예: `handwritten_answers.pdf`)을 학생 단위 단일 이미지 파일들로 분할합니다.
```bash
python3 scripts/split_pdf.py [답안지PDF경로] [출력폴더경로]
```

### 2단계: `view_file`을 통한 손글씨 수기 답안 해독 및 교차 검증 (필수)
분할된 수기 이미지(예: `student_001.png`, `student_002.png` 등)를 `view_file` 도구로 **하나도 빠짐없이** 직접 조회하여 다음 사항을 시각적으로 해독합니다:
- 학생 이름/학번/번호 식별
- 지우개 자국, 연필 흔적, 흘림체 노이즈를 문맥 기반으로 구분하여 본문 텍스트 정확하게 파악
- 서술형 답안의 논리적 전개, 근거 제시 타당성, 핵심 키워드 포함 여부 판독

### 3단계: 루브릭(채점 기준표) 기반 다차원 정량 채점 및 정성 피드백 생성
교사가 지정한 채점 기준(예: 내용 타당성, 구조 응집성, 어문 규범 등)을 기준으로 항목별 점수를 산출하고 다음과 같은 성찰 피드백을 작성합니다:
- **영역별 정량 점수**: 루브릭 항목별 수치 배점 합산
- **학생 맞춤형 피드백**: 학생 이름을 직접 호명하며 강점과 보완할 점을 멘토링 어조로 서술
- **나이스(NEIS) 세특 연계 총평**: 교과 세부능력 및 특기사항에 즉시 이식 가능한 고밀도 정성 서술 문장 생성

### 4단계: 엑셀 / CSV 채점 시트 자동 저장
모든 학생의 채점 결과, 영역별 점수, 정성 피드백, 세특 총평을 `채점결과.csv` 또는 `채점결과.xlsx` 파일로 누적 저장합니다.
